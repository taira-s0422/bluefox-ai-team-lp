30秒でわかる要約

  • 何を八戸市内の中小企業向けに、LINEで頼める小さな制作依頼（バナー・SNS画像・簡単な資料など）を、AIと人で最短翌日に返す月額サービス。
  • いくらで月5万〜25万円の3プラン。価格は世の中の相場に合わせて決め、AIで浮いた時間は値下げせず利益にする。
  • 儲かる見込み2人体制・保守的な見込みで、立ち上がりは赤字、9か月目ごろに黒字化、12か月目で粗利率約41%。仮定
  • 決めていただきたいこと確認4件と、根拠つきのご提案3件。
  • 次にやることまず実際に1点作って、かかる時間を測る。この計画で一番重要な数字を、仮定から実測に置き換える。

1ひとことで

人がAIを使いこなして仕事にかかる時間を大きく減らし、高い利益率で回す事業です。値段は世の中の相場に合わせて決め、AIで減らした時間は値下げに回さず、こちらの利益にします。

詳しく見る

原価をそのまま積み上げて値段を決めると、AIで効率化するほど値段を下げなければならず、効率化の成果が自社に残りません。そこで値段は競合の相場を基準に決め、原価（人の作業時間）が下がった分は利益として確保します。

2市場と地域

まず八戸市内の企業から始めます。八戸市内だけで、対応できる社数をはるかに上回る見込み顧客がいるため、当面は地域を広げず八戸での検証を優先します。広げる順番は八戸市 → 青森県内 → 東北 → 全国を想定しています。

詳しく見る
  • 全国で見ると、生成AIを仕事に使っている企業は約3割強という調査があります（帝国データバンク調査）。導入はしたが使いこなせていない企業は一定数いると見られます。
  • 八戸市内で同じ条件に当てはまる企業は、1,500〜1,900社程度仮定と推計しました。市の統計ではなく、全国の数値を人口の比率で割り戻した推計です。
  • この数は、後述する対応できる社数（数十社規模）よりはるかに多いため、地域を広げる目的は件数の確保ではなく、八戸で検証を終えてから次に進むことと位置づけています。

4サービスの形

  • 誰に：八戸市内の中小企業で、AIを導入したが使いこなせていない担当者の方
  • 何を：バナー・SNS画像・簡単な資料など、小さな依頼が主役。システム開発など大きな依頼は個別相談
  • 料金：LIGHT 5万円／STANDARD 12万円／BUSINESS 25万円（税別・目安）
  • 約束：「最短翌日」はバナー・画像・Webページ1ページまで。契約期間の縛りなし、毎月自動更新
詳しく見る

「最短翌日」の条件：Webページ1ページは、原稿と写真などの素材がそろっていることが条件です。そろっていない場合は、そろってから翌日の対応になります。

対象外とする依頼：有償のライセンス費用が発生する素材、規制業界の広告審査が必要なもの、プランの上限を大きく超える開発案件。

契約：最低契約期間は設けず、毎月自動更新とします（直接の競合と同じ条件です）。

計算の前提

  • 売上 ＝ 12万円 × 契約社数
  • 費用 ＝ 人件費120万円（月60万円×2人・実働160時間/月）＋ AIツール費（1社あたり月3,000円）＋ 間接費10万円
  • 粗利率 ＝（売上 − 費用）÷ 売上
  • 粗利率50%以上には約23社、30%を割るのは約16社を下回る場合
  • 1社あたり月の作業時間は8時間と仮定（実測で確かめる対象）

6見直しの基準

利益率の目標は50%以上とします。粗利率30%割れが当たり前の状態が続いたら、料金や体制を見直します。始める前に基準を決めておくと、始めた後の判断がぶれません。

詳しく見る

「当たり前になった」をどの契約社数で判断するかは、社長と一緒に決めたいと考えています。試算では、粗利率30%を割るのは契約社数がおよそ16社を下回る水準です。

ご確認したいこと

  1. 試算では、粗利率30%を割るのは契約社数がおよそ16社を下回る水準です。この数字を見直しの基準にしてよいか確認したいです。
  2. BUSINESSプランに含める「小規模システム開発1〜2件」は、相場に照らすとこの価格に収めるのが難しい可能性があります。個別見積りにする、対象を絞るなど、扱いを決めたいです。
  3. 収支は2人の役割の組み方によって大きく変わります。どの組み方に近づけるか、既存の業務とどう兼ね合いをつけるかを確認したいです。
  4. 最初のお試し先について、いつ・どなたからお声がけを始めるかを確認したいです。

ご提案と根拠

① 依頼を「ポイント」で管理する
「バナー4〜6点」のような個数の枠ではなく、依頼ごとにポイントを割り振ります。
根拠：同業のサービスでも「時間や回数で区切り、超えたら追加料金」という管理方法が公式に採用されています。難易度の違う依頼を公平に扱えます。

② 最初の数社はお試し価格で検証する
八戸市内でお声がけできる3〜5社に、3か月間、通常の8割程度の価格で契約していただき、実際の作業時間を測ります。
根拠：この事業は「1社あたり月に何時間かかるか」がまだ読めていません。安く確かめてから本格化するほうがリスクを抑えられます。

③ 地域を広げるタイミングを決めておく
契約社数が対応できる上限の8割程度に達したら、青森県内への拡大を検討します。
根拠：八戸市内だけでも対応できる件数を大きく上回る需要が見込めます。無理に広げるより、八戸での検証を先に終えるほうが手堅いと考えます。

8ネクストステップ

  1. 工数の実測：実際に1点作って、かかる時間を測る
  2. 実測の結果をもとに、料金と体制を確定する
  3. 八戸市内の取引先から、最初の数社をお試し価格でお受けする
  4. 結果を見ながら、正式な料金と体制に移行する
  5. 手ごたえを見ながら、青森県内への展開を検討する
詳しく見る（工数の実測の内容）

何を測るか：バナー・SNS画像・Webページ1ページ・簡単な資料・LPデザインを、種類ごとに1〜2点、実際の依頼に近い形で試作します。

何を記録するか：依頼の整理とAIへの指示づくり、AIの出力を待つ間に人が張り付いていた時間、AIの出力を直す時間、最終チェックの時間を、分単位で記録します。

結果で何が決まるか：「1社あたり月に何時間かかるか」が実測値になれば、プランの中身・対応できる社数・粗利率の見込みを仮定から実測に置き換えられます。目安（例：月9.7時間以内）に収まれば計画どおり進め、収まらない場合は、値段を上げるのではなくプランの中身（できることの量）を見直す案を検討します。

本資料の数字は、断りのない限りすべて仮定です。実際の作業を通じて順次実測値に置き換えていきます。
